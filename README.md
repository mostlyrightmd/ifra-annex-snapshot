# IFRA 51st Amendment annex snapshot

A copy of the International Fragrance Association (IFRA) workbook "Annex on contributions from other sources to the IFRA Standards", notified with the 51st Amendment.

- Original: https://d3t14p1xronwr0.cloudfront.net/docs/Standards-Documentation/ifra-51st-amendment-annex-on-contributions-from-other-sources.xlsx
- Linked from: https://ifrafragrance.org/initiatives-positions/safe-use-fragrance-science/ifra-standards/ifra-standards-documentation
- Original SHA-256: `28988a6c543db4b7aa3e39229bc543154b0df6b59f773726f2a4f2936f271bef`
- Retrieved: 2026-10-07

The only change is that the single cell hyperlink on sheet "Natural contributions" (cell E5, pointing at IFRA's procedure PDF) was removed, together with its relationship entry. Every cell value on every sheet is unchanged.

`ifra-51st-amendment-annex-natural-contributions.csv` holds the same sheet as CSV: rows 8 to 1038, columns A to J, cell values as stored. The header row is renamed to plain identifiers in the same column order (IFRA amendment, NCS category, RIFM id, principal CAS, other CAS, NCS name, botanical name, constituent CAS, constituent name, constituent concentration in percent).

Source of the data: IFRA. The content belongs to IFRA. This copy exists so a spreadsheet reader that refuses workbooks with external hyperlinks can open the file. Check the individual IFRA Standards when in doubt.
